# Lovecraft Euroia

A shared collection of tools and automations that make daily work more efficient, more comfortable and clearer: time-estimate tracking, desktop and keyboard setup, server utilities, language-learning helpers and similar small systems.

# Name

**Euroia** (Greek εὔροια, pronounced "eu-ROY-a") means "good flow" or "flowing smoothly": *eu* (good) + *rhoia* (a flowing). The word was used for rivers and for the body's fluids flowing well.

In Stoic philosophy it became a definition of happiness. Zeno of Citium, the founder of the Stoic school, described the good life as *euroia biou*, "a smooth flow of life".

The name states the goal of the majority of repositories here:

- Work and life flow without friction.
- Repetitive tasks run on their own.
- The current state of things is clear at a glance.
- Less friction and more progress.
- More comfort, more ease.

# Repositories

Each tool has its own repository, named `<family>-<tool>`.

## Apatheia server

- `apatheia-momentum`: time-estimate accountability. It compares each task's estimate with the real time spent and shows the running task, its remaining time and the day's streak in the desktop bar.

## Desktop

- `speech-to-text`: speech to text in any window; transcribes speech and pastes it at the cursor.
- `screen-temperature`: screen colour temperature by sunrise and sunset, through gammastep.
- `download-router`: fuzzy folder picker (fzf in kitty) for browser save and upload dialogs and for Thunar.
- `cc-workos`: documentation of the desktop setup (Hyprland, kanata, espanso, Obsidian, browser tools), the user manual and the TickTick userscript.

## Browser extensions

- `browser-web-kb-navigator`: Firefox / LibreWolf extension to move through search results with the keyboard.

## Obsidian

- `obsidian-notes-ai`: local assistant that answers questions about the Obsidian vaults, with links to the source notes.
- `obsidian-sync`: keeps a `_shared` folder identical between two Obsidian vaults.
- `obsidian-sidebar-outline`: plugin showing the current note's outline in the left sidebar, with fuzzy search.
- `obsidian-tab-mover`: plugin to move the active tab left or right in its tab bar.

## Language learning

- `lang-anki`: Anki flashcards generated from copied words, with audio, a grammar table and examples.
- `lang-anki-walk`: audio-only Anki cards for practising Russian while walking.
- `lang-anki-writer`: Anki cards for Russian writing practice from Language Reactor exports.
- `lang-ru-shadow-typing`: Anki template for Russian shadow typing from audio.
- `lang-dragoman`: input bar for writing in a foreign language; an LLM corrects the sentence and the user retypes it.
- `lang-quick-add-word`: select a word on any device and get a full Anki card for it (audio, translation, grammar, examples), synced to AnkiWeb.
- `lang-sayso`: speaking practice: proposes conversations from Obsidian notes and helps deliver them in the language being learned.
